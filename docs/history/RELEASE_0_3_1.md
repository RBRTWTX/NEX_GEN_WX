# NextGen Weather Studio 0.3.1

Version 0.3.1 is a Windows build-cache reliability repair for the 0.3.0 observation and temperature release.

## Corrected

Tauri and Cargo generated build metadata can contain absolute paths. When a compiled `src-tauri/target` folder is retained while the project is copied or renamed, those generated paths may still point to the previous project folder. The result is a build failure while Tauri reads autogenerated permission files such as `app_hide.toml`.

The launchers now run `scripts/prepare-windows-build-cache.ps1` before validation or compilation. The script records the active project root in `src-tauri/target/.ngws-project-root.txt`. When the project path changes, or when an older untracked cache is first encountered, only the Tauri and NextGen Weather Studio generated build metadata is removed. Other compiled dependency artifacts are retained where possible.

A manual `repair-nextgen-build-cache.bat` launcher is included for forced repair.

## Upgrade

1. Close all NextGen Weather Studio command windows.
2. Apply the 0.3.1 repair patch to the folder containing 0.3.0.
3. Choose **Replace the files in the destination**.
4. Run `repair-nextgen-build-cache.bat` once.
5. Run `setup-nextgen-weather-studio.bat`.
6. Run `run-nextgen-weather-studio.bat`.

Do not manually copy generated files from one `src-tauri/target` folder into another project unless the build-cache preparation script is present.
